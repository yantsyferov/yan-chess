Vertical slices of the game board feature. After each slice the whole app must be startable (`pnpm --filter api dev`, `pnpm --filter web dev`) and the slice's new user-visible value verifiable in a browser.

The feature is pure frontend — no backend changes. Agents referenced in `**[Agent: ...]**` live in `.claude/agents/`. QA agent for the final regression slice: `testing-expert`.

- [x] **Slice 3: Chess clocks tick, pause, warn, flag-fall**

  > Clocks appear above and below the board. The clock of the active side counts down with ~100ms UI granularity; the opponent's clock pauses. Under 10 seconds, the active clock shows warning color and tenths of seconds. When a clock reaches 0, the game ends immediately (result stored; result modal lands in Slice 4).

  - [x] Task: Create `apps/web/src/features/game/clock-math.ts` — pure helpers. `formatClock(ms)` returns "3:00" when ≥10s, "9.3" when <10s (and ≥0), "0.0" when 0. `isLowOnTime(ms)` returns true when `ms < 10_000`. `wouldOpponentHaveMatingMaterial(chess, flaggedSide)` returns true when the opposite side has material sufficient to mate (any pawn, rook, or queen → true; a lone knight or bishop → false; two or more minor pieces of any mix → true). Pure, no chess.js side-effects. **[Agent: react-frontend]**
  - [x] Task: Extend `useGameStore` with real clock actions. `startGame()` initializes `clock = {white: modeMs, black: modeMs, activeSide: "white", lastTickAt: performance.now()}` using mode → ms mapping (bullet=60_000, blitz=180_000, rapid=600_000, classical=1_800_000). `tickClock(deltaMs)` deducts from `clock[activeSide]`; if result ≤ 0, call `endGame({winner: oppositeSide if hasMatingMaterial else "draw", reason: "flag_fall" | "flag_fall_insufficient_material"})`. On successful `makeMove`, flip `activeSide` and reset `lastTickAt = performance.now()`. Add `endGame({winner, reason})` that sets `phase = "ended"`, writes `result`, and sets `clock.activeSide = null` to stop ticking. **[Agent: react-frontend]**
  - [x] Task: Create `apps/web/src/features/game/useGameClock.ts` — React hook that runs a `requestAnimationFrame` loop while `clock.activeSide !== null`. On each frame reads `performance.now()`, computes delta vs `lastTickAt`, calls `tickClock(delta)`, and updates `lastTickAt`. Cleans up on unmount. Also listens to `document.visibilitychange`: when the tab becomes hidden, remember the hide time; when it becomes visible, compute elapsed and tick once (don't lose time while backgrounded). Mount the hook inside `Game.tsx` so it runs for the whole game lifetime. **[Agent: react-frontend]**
  - [x] Task: Create `apps/web/src/components/game/Clock.tsx` — props `side: "white" | "black"`. Reads `clock[side]` + `clock.activeSide` from the store. Renders the formatted time (via `formatClock`) in a large readable style. When `isLowOnTime(clock[side])` is true: text color = `text-danger`. When `clock.activeSide === side` AND game is playing: subtle pulse / border highlight to indicate "your turn". Fixed-width tabular numerals so digits don't jitter. **[Agent: react-frontend]**
  - [x] Task: Lay out `<Clock side="black" />` above the board and `<Clock side="white" />` below the board inside `Game.tsx` (phase === "playing" branch). **[Agent: react-frontend]**

- [x] **Slice 4: End-game detection by chess rules + Result modal + "New game"**

  > After every move, chess.js's end-game checks fire. Checkmate / stalemate / insufficient material / threefold repetition / 50-move rule all end the game automatically. A ResultModal appears over the board with the correct text. "New game" resets to the mode selector; "Close" hides the modal and keeps the final position visible without allowing further moves.

  - [x] Task: Create `apps/web/src/features/game/game-end.ts` — pure function `detectGameEnd(chess)`: returns `{winner, reason} | null`. Order of checks: `isCheckmate` → winner is the side that just moved; `isStalemate` → draw/stalemate; `isInsufficientMaterial` → draw/insufficient_material; `isThreefoldRepetition` → draw/threefold_repetition; `isDrawByFiftyMoves` → draw/fifty_move_rule. Returns null when the game continues. **[Agent: react-frontend]**
  - [x] Task: Wire `detectGameEnd` into `useGameStore.makeMove`. After a successful chess.move, call detectGameEnd(chess); if non-null → call endGame({winner, reason}).
